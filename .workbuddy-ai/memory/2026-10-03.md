# 2026-10-03 — header polish, single email, Antiques & Collectibles vertical

## Logo `.com` clipped (user report)
The wordmark crop used a hardcoded `x1=1114` but the source artwork's final "m" reaches
`x=1154` — 40px was chopped. Fixed by measuring the real content bands (emblem `x 244..1013`,
wordmark `x 147..1154`) and deriving crops from measurements + padding instead of guessing.
Regenerated every asset in `public/brand/` and the favicons. Final intrinsic sizes now
declared in `components/Logo.tsx`: mark `400x235`, lockup `900x192`, OG `900x473`
(the OG `height` in `app/layout.tsx` was stale at 606 and is now 473).

## "Post ad" was an empty blue pill (user report: "fix the blue button")
**Pre-existing CSS specificity bug, not the new palette.** `.account-actions a` (`0,1,1`)
outranked `.post-button` (`0,1,0`), so the button's white label was repainted brand-blue on
a brand-blue fill. Fixed with scoped `.account-actions a.post-button` rules rather than
`!important`.

## Bug found while verifying: duplicated group list → silent data corruption
`app/admin/(panel)/categories/page.tsx` held its own hardcoded `GROUPS` array missing the new
group. The Group `<select>` therefore had no option matching `Antiques & Collectibles`, so
opening one of those categories and saving would silently reassign it to the fallback
option. Nothing threw.
Fixed by deleting the copy and importing the canonical list. Because `lib/models/Category.ts`
imports mongoose, the list was first extracted into **`lib/category-groups.ts`** (no
dependencies) which the model re-exports — importing the model into a client component would
have pulled the whole ODM into the browser bundle.
